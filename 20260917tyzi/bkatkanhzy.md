# 关于取卵的若干问题

> 更新时间：2026-09-17 (UTC+8)

取卵是在试管婴儿过程中，待卵泡发育成熟后，医生在B超引导下经阴道穿刺取卵，将取得卵放到胚胎培养皿中，然后在培养室中培养。

Q

取卵术前后要注意什么？

1）取卵日夫妻双方均需带身份证、结婚证到生殖中心报到。

2）取卵术前、术后3天避免性生活。

3）取卵术是在B超指引下经阴道穿刺取卵，大概10分钟左右即可做完，故不必紧张。

4）取卵术后，休息2小时左右，可能会有头晕、恶心、呕吐，多数是止痛针引起，下腹可能会有隐痛，休息后症状可缓解，术后应尽早解小便，经医生同意，无不适方可回家。如剧痛难忍，或有阴道出血，要立即告知医生或立即急诊就诊。
A

Q

取卵后，对以后的卵巢功能有没有影响？

取卵后卵巢需要一段时间恢复至取卵前状态，一般对以后的卵巢储备功能没有影响。
A

Q

取卵后，肚子感觉不舒服，是怎么回事呢？该怎样处理呢？

取卵后会有轻微的下腹不适，一般2-3天缓解或消失；如果取卵数量较多有可能发生卵巢过度刺激症状：腹胀、恶心、呕吐、呼吸困难、尿少等，此时您需要尽快复诊，并避免剧烈活动。
A

Q

我的卵巢功能低下，每次只有1-2个卵泡生长。为什么有时候取不到卵子？

卵泡与卵子不是同一个概念，有卵泡生长不一定有卵子。对于卵巢功能低下的患者，有时可能会出现卵泡为空卵泡的现象，在穿刺抽吸卵泡时未发现颗粒细胞，也没有卵子。同时，卵泡经线过大或过小均可能影响获卵情况。
A

Q

为什么B超下监测到的卵泡数可能会多于取卵手术获得的卵子数？

医生在做B超时，同时对双侧卵巢上卵泡进行了监测记录，记录中有一些卵泡经线较小未成熟，取卵手术中可能未能获卵。也有部分卵泡内无生长发育的卵子。
A

Q

为什么有的卵子不受精？

卵子受精是一个复杂的过程，目前科学研究还没有完全了解受精整个过程中的机制。目前知道的受精过程包括卵子要成熟、精子要获能、发生顶体反应并穿过卵子透明带、精子与卵膜融合、卵子发生皮质反应、卵子恢复减数分裂、形成雌雄双原核。在这些过程中任何一个环节有问题，都会导致受精失败。在试管婴儿技术中，卵子不受精的可能原因包括卵子不成熟、卵子成熟了但质量有问题、精子形态及功能异常，从而影响上述受精过程中的某一个或多个环节。
A

Q

取卵之后，没有成功培育形成胚胎往往是什么原因？为什么卵子可以取了，医务人员又说，有的卵子质量不好，不能进行培育呢？

卵子的质量需要取出 后，在培养室高倍显微镜观察下才能得以评估。取卵后由于卵子退化或不成熟，可能不受精，造成没有胚胎可移植。女方年龄较大或卵巢早衰的患者，有可能卵子退化或不成熟。
A
